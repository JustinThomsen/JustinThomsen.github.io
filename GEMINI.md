# JustinThomsen.github.io

## Overview
This repository contains the personal website and portfolio for Justin Thomsen, hosted via GitHub Pages.

## Project Structure
- `index.html` - Main landing / home page
- `aboutme.html` - About Me page
- `references.html` - References page
- `css/` - Stylesheets and SCSS source files
- `js/` - JavaScript files
- `img/` - Images and media assets
- `fonts/` - Font assets (Font Awesome)
- `resume/` - Resume files

## Tech Stack & Tooling
- **HTML5 & CSS3 / SCSS**
- **Bootstrap 4** & **Font Awesome**
- **jQuery** & **Popper.js**
- **Lite-Server** for local live-reload development
- **Node.js & npm**

## Development Commands
When running on Windows PowerShell, use `npm.cmd` if script execution policies apply:
- `npm run lite`: Starts the local lite-server development server
- `npm run scss`: Compiles SCSS files to CSS
- `npm run build`: Cleans, copies fonts, optimizes images, and runs usemin into `dist/`
